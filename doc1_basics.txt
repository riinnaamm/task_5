Python — це високорівнева мова програмування з динамічною типізацією. Основні типи даних у Python включають цілі числа (int), числа з плаваючою крапкою (float), рядки (str) та булеві значення (bool). Для роботи з колекціями використовуються списки (list), кортежі (tuple), множини (set) та словники (dict).
